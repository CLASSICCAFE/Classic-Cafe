WHATSAPP ADMIN AUTO MESSAGE
For automatic WhatsApp notifications to the Admin, add these Cloudflare Worker Secrets:
WHATSAPP_TOKEN
WHATSAPP_PHONE_NUMBER_ID
WHATSAPP_ADMIN_TO

Optional for WhatsApp Business approved-template delivery:
WHATSAPP_TEMPLATE_NAME
WHATSAPP_TEMPLATE_LANG (default: en_US)
WHATSAPP_API_VERSION (default: v22.0)

The new-order notification contains: Order ID, time, customer name/mobile, address, distance, every item + quantity + offer, food total, delivery charge, grand total, payment method, NEW status and tracking link.

If template mode is not configured, V13 sends a text notification. The Worker logs a WhatsApp API error if delivery fails and the order itself is still saved successfully.

ADMIN_KEY_2 (optional second Admin login key)
The code does not fail the order if WhatsApp sending is unavailable.
